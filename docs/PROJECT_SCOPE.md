# Savor Scope

## Problem
Restaurant ratings do not answer:
"What dish should I order?"

## Solution
A social food diary that enables:

- Logging dishes
- Dish-level reviews
- Personalized recommendations
- Semantic search
- Social feed
- Analytics dashboard

---

## In Scope

- Web application
- REST API
- PostgreSQL
- Redis caching
- Recommendation engine
- NLP pipeline
- Semantic search
- Social features
- Analytics dashboard

---

## Out of Scope V1

- Native mobile apps
- Messaging
- Restaurant dashboard
- Reservation integration
